**Điểm mạnh**

- Có một luồng sản phẩm liền mạch: task → availability → proposal → apply → execution → learning/risk. Có thể hiện thực một demo có ý nghĩa, vượt mức CRUD đơn giản.
- Phân lớp Api/Application/Domain/Infrastructure, hợp đồng DTO, nullable và warnings-as-errors giúp bảo trì. Planner tách khỏi EF/HTTP nên dễ kiểm thử.
- Authentication được đầu tư: Argon2id, OTP có purpose và counter, hash refresh token, rotation/reuse detection, kiểm tra session còn hiệu lực trên protected request, audit và thông báo đổi mật khẩu có outbox.
- Browser session dùng cookie HttpOnly/Secure/SameSite, có header và origin check cho mutation. API kiểm tra ownership; model workload dùng composite FK gồm UserId; Admin API kiểm tra role.
- Proposal có revision, expiry và trạng thái dùng một lần. Mutation có transaction và account lock trên SQL Server; phiên đang chạy được ràng buộc ở DB. Bộ test có owner isolation, token invalidation, planner invariant và ca concurrency thực.
- Có lock file dependencies, migration, script kiểm tra trước merge và workflow CI yêu cầu SQL Server. Đây là các nền tảng vận hành tốt, dù CI bên ngoài chưa được xác minh ở lần đánh giá này.
