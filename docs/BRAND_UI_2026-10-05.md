# PLANORA — logo và UI xanh–trắng

Theo ảnh tham khảo do người dùng cung cấp, cụm thương hiệu đã chuyển sang:

- Biểu tượng P dạng dải lụa cyan/blue, có độ bóng và nền trong suốt.
- Wordmark **PLANORA** in hoa màu navy.
- Tagline **Plan smarter. Work realistically.**

Ảnh được dựng theo mẫu bằng imagegen; không phải file vector gốc của ảnh tham khảo.

## Tích hợp

- `src/SPWPOS.Api/wwwroot/assets/planora-brand.png`: cụm P, wordmark và tagline, PNG RGBA 2158×729.
- `src/SPWPOS.Api/wwwroot/assets/planora-mark.png`: biểu tượng độc lập cho favicon và trạng thái tải.
- `brand.js`: markup thương hiệu dùng chung, giữ đúng tỷ lệ và nhãn đọc cho công cụ hỗ trợ.
- Sidebar, đăng nhập desktop/mobile và tiêu đề tab trình duyệt đã dùng thương hiệu mới.
- Bảng màu dùng cyan/blue làm màu nhấn, nền xanh rất nhạt, card trắng và chữ navy. Cảnh báo vẫn dùng màu để phân biệt rủi ro/lỗi.
- Chart đã đổi chú thích thành xanh đậm cho dự kiến và xanh nhạt cho thực tế.

## Kiểm tra

71 kiểm tra UI và 17 kiểm tra thương hiệu trên Edge headless đều đạt. Kiểm tra thương hiệu gồm ảnh tải đúng, nền có alpha, desktop/mobile không tràn ngang, màn hình 320px, tiêu đề trình duyệt và CSP. Không có lỗi JavaScript hoặc toast lỗi trong các màn hình kiểm tra. Ảnh chụp và kết quả nằm trong `artifacts/ui/`; dữ liệu trên dashboard là dữ liệu mẫu.

Chạy lại:

```powershell
node tests/browser/ui-preview-server.cjs
node tests/browser/ui-browser-check.cjs
node tests/browser/ui-browser-check.cjs --brand-only
```

Kiểm tra dùng Windows, Edge và Node.js 20.18+; API mẫu không kết nối dữ liệu production.
